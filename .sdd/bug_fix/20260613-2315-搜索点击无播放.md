# Bug 修复报告：顶栏搜索点击无跳转播放

## 用户原话

> 前端搜索调用接口获取了返回，点击其中的搜索结果之后，前端不跳转对应显示

## 经验回查

- 是否存在相关历史经验：**是**
- 相关条目：
  - `[T-001]`：GlobalSearch 与 SongSummary 字段对齐
  - `chatStore`：`setRecommendations` + `playSong` 联动播放器
- 结论：搜索 UI 只做了路由跳转，未接入播放器状态，属于实现遗漏

## 为什么已有经验仍然犯错

1. T-001 只验收了搜索请求与 Mock 数据格式，未验收「点击结果后的播放闭环」
2. GlobalSearch 在 Mock 阶段可能只检查了 `navigate('/player')`，未绑定选中歌曲

## 问题分析

- **现象**：搜索「一半一半」有 8 条结果，点击后页面无对应歌曲展示/播放
- **影响范围**：顶栏 `GlobalSearch` 全部搜索点击与回车
- **直接原因**：`onClick` 仅 `navigate('/player')`，未调用 `playerStore`
- **根本原因**：搜索组件与播放器状态未联动，播放页仍显示默认种子推荐

## 修复方案

- **修改文件**：`frontend/src/components/GlobalSearch.tsx`
- **修改说明**：
  1. 点击/回车时将搜索结果转为 `PlayerSong[]` 并 `setRecommendations`
  2. 跳转 `/player` 后对选中项调用 `playSong`
  3. 播放失败时用 `message.warning` 提示

## 验证方式

- **前端验证**：
  1. 顶栏搜索「一半一半」
  2. 点击 Top Barry 版本
  3. 应跳转播放页，左侧推荐列表为搜索结果，中间播放器显示并播放该曲
- **终端验证**：搜索 API 已正常，无需额外后端改动
