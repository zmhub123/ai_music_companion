# Bug 修复报告：新生成曲谱和弦指法缺失

## 用户原话

> 新歌曲生成琴谱时和弦指法缺失，请修复

（截图：《Good Time》曲谱右侧 Gm7 / Cm7 / D#maj7 / G#maj7 指法图为空网格）

## 经验回查

- 是否已有相关经验：**否**（指法图模块无专项记录）
- 结论：AI 扒谱可输出任意和弦名，但前端 `chordShapes.ts` 仅覆盖 Mock 种子常用和弦

## 问题分析

- **现象**：新生成曲谱和弦名正常显示，指法图只有空六线格
- **影响范围**：所有经音频分析/LLM 生成的非种子和弦
- **直接原因**：`resolveChordShape('Gm7')` 等返回 `undefined`，`ScorePanel` 回退 `{ tops: [], dots: [] }`
- **根本原因**：指法库过小；解析器无法处理 `m7`/`maj7` 及 `D#`/`G#` 等升号根音

## 修复方案

- 扩展 `GUITAR_CHORD_SHAPES` / `UKULELE_CHORD_SHAPES`：Gm7、Cm7、Ebmaj7、Abmaj7 等
- 重写 `resolveChordShape`：升号→降号等价、`m7`/`maj7` 多级回落查找
- 未命中时 `ChordDiagram` 显示「暂无指法」而非空网格

## 验证方式

- 刷新页面，重新打开《Good Time》曲谱，右侧应显示 Gm7/Cm7/D#maj7/G#maj7 指法点
- 终端：`node --input-type=module -e "import { resolveChordShape } from './src/constants/chordShapes.ts'; ..."`
